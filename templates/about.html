About the project

What is CartIQ?

🛒

The idea

CartIQ is a grocery market-basket intelligence system built with Python, Pandas and scikit-learn. It uses the Kaggle Instacart Market Basket Analysis dataset to learn how people shop.

🎯

The goals

The project is built around two prediction outcomes: the value (size) of a customer's basket, and whether a product will be reordered — supported by a complete preprocessing pipeline.

🐍 Python 🐼 Pandas 🧠 scikit-learn 🔥 Flask 📊 Matplotlib · Seaborn
