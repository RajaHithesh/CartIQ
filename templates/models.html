Table 2 · Regression

Predicting basket size

A different task: instead of yes/no, these models predict the number of items in the basket. They are judged with error metrics, not F1. R² = 0.0108 means the linear model explains only about 1% of the variation in basket size — so basket size is not predictable from these features. The regression part is a learning exercise; the classification side is where the project performs well.

Table 3 · Unsupervised

Clustering and dimensionality reduction

These models have no target label to learn from, so they cannot predict reorder. They are used to group customers by shopping behaviour (K-Means, Hierarchical, DBSCAN) and to compress and visualise the 14 features (PCA, t-SNE). Higher silhouette = better separated clusters.

Table 4 · Hyperparameter tuning

GridSearchCV — before vs after

Instead of guessing the settings, GridSearchCV tried every combination in a grid and kept the one with the best cross-validated F1 (5-fold StratifiedKFold, scoring="f1" — 270 model fits in total). Tuning used only the training data; the test set was opened once at the end. The gains are small because the original hand-picked settings were already close to optimal — a useful finding in itself.
